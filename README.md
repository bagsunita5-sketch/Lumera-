# LUMÉRA storefront

A responsive furniture storefront built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```sh
npm install
npm run dev
```

## Build for production

```sh
npm run build
npm run preview
```

The cart is saved in the current browser. Checkout is a front-end demonstration and does not submit an order or process payment. Product pricing, specifications, contact details, and photography are illustrative placeholders and should be replaced with approved business information before launch.
